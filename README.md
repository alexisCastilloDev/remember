# Los recuerdos de un loco que te amo
1. Copiá tus fotos y videos de Drive a la carpeta `media/` (con el mismo nombre de archivo).
2. Editá `data.js`: fecha, archivo y (opcional) una frase propia por recuerdo.
3. Subí todo a GitHub e importá el repo en Vercel (sitio estático, sin configuración).
Para probar en tu PC: `npx serve .`
